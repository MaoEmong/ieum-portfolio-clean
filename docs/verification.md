# 검증 범위와 한계

기준일: **2026-09-08**. 아래의 서비스 검증은 당시 내부 실행 기록과 배포 기록을 재정리한 것입니다. 민감정보가 포함될 수 있는 원본 로그는 배포하지 않으며, 이 문서 작성 과정에서 서비스 전체 테스트를 새로 실행한 것은 아닙니다.

## 서비스 v1의 확인 기록

| 구분 | 당시 확인한 결과 | 해석할 때의 제한 |
|---|---|---|
| 앱 기본 테스트 | 834개 통과, 조건부 스킵 17개 | 코드 커버리지 비율이 아님 |
| 조건별 앱 검사 | flavor 대상 검사를 별도로 실행 | 기본 수치와 중복될 수 있어 합산하지 않음 |
| 백엔드 | 테스트 210개 통과 | 모든 실사용 입력을 검증한 것은 아님 |
| 정적 분석·빌드 | 앱 정적 분석, Android arm64 release-mode, 백엔드 Docker 빌드 | 스토어 서명·스토어 출시와 다름 |
| CI·배포 | PR·main CI 성공과 해당 소스의 스테이징 배포 확인 | health 응답만으로 배포를 판정하지 않음 |
| 파일 보존 | 신규 합성 사진 1개를 서버 재배포 후 새 앱 프로세스에서 재조회, 바이트 대조 | 기존 원본 복구·모든 파일 검증은 아님 |

기본 실행의 조건부 스킵 17개 중 flavor 관련 16개는 해당 환경 검사로 나눠 실행했습니다. 로컬 서버·AI E2E 1개는 해당 배포 전 작업에서 실행하지 않았습니다. 조건별 검사와 기본 검사는 항목이 겹칠 수 있으므로 총합을 제시하지 않습니다.

Android 검증 앱은 로컬 테스트 인증서를 사용한 release-mode 산출물입니다. 새 기기 설치·기존 로그인과 모델 보존 확인을 신규 소셜 로그인 전체 또는 모델 추론 품질 확인으로 해석하지 않습니다.

## 명시적으로 남겨 둔 범위

- 기존 누락 원본 복구는 완료하지 못했습니다. 기록·전사문·참조 보존과 구분합니다.
- 실제 AI 약속 추출·검색의 정확도와 환각 발생률은 확정된 수치가 없습니다.
- 이번 배포 확인이 음성 전체 흐름, 다른 계정의 실서버 접근, 전체 앱 시나리오 재검증을 뜻하지 않습니다.
- iOS 실기기, 스토어 서명·출시, 알림, 외부 캘린더 연동은 완료 범위가 아닙니다.
- 제한된 부하 검사 결과로 최대 동시 사용자 수나 최대 처리량을 주장하지 않습니다.

## 이 포트폴리오 저장소의 검증

서비스 코드 전체와 분리된 독립 예제의 현재 검증은 아래 명령과 GitHub Actions에서 확인할 수 있습니다.

| 공개 예제·검사 | 2026-09-08 로컬 결과 | 범위 |
|---|---|---|
| Java·Spring 정상 계약 | 20개 통과, 결함 데모 2개는 기본 스킵 | MockMvc 9개 + Spring 컨텍스트 11개 |
| 별도 결함 주입 데모 | 의도한 계약 실패 2개 탐지 후 정상 구현에서 같은 2개 통과 | 오늘 만든 결함 모델, 과거 서비스 수정 전 코드 아님 |
| Dart 보조 예제 | 38개 통과 | 재시도·시각 보존 |
| 공개 범위 검사기 자체 테스트 | 61개 통과 | 정상 dependency namespace 허용 및 민감 패턴 유지 |

Java는 JDK 21·Maven 3.9.16에서 확인했습니다. CI의 Maven은 실행기 설치 버전을 사용하므로 로컬과 동일 버전이라고 단정하지 않습니다. 고정된 POM/BOM과 실행 명령을 함께 보관합니다.

```sh
cd examples/backend-boundaries
mvn --batch-mode --no-transfer-progress verify
python scripts/red_green.py
```

다음은 저장소 루트에서 시작하는 보조 검사입니다.

```sh
python scripts/check_disclosure.py
python -m unittest discover -s scripts/tests
cd examples/reliability
dart pub get
dart format --output=none --set-exit-if-changed .
dart analyze --fatal-infos
dart test
dart run example/main.dart
```
