# AI 협업 의사결정·검증 요약

프로젝트 주도자(지원자, 이하 주도자)의 요구·승인과 AI가 지원한 기술 작업을 구분해 정리했습니다. 실제 개발 대화와 사후 기록을 편집한 설명이며, 직접 인용이나 당시 AI 답변의 재현이 아닙니다.

## 역할과 의사결정

| 개발 과제 | 주도자의 요구·승인 | AI가 지원한 작업 | 결과를 판단한 기준 |
|---|---|---|---|
| 개발·배포 환경 분리 | 개발 환경의 SNS 로그인 생략, 배포 환경의 실제 인증·테스트 후 배포라는 작업 흐름 지정. 배포 설정 상태 제공 | 설정 누락과 잘못된 저장 모드 조합 조사, 기동 조건 보완, 설정·SDK 계약 검사 | 잘못된 조합의 기동 거부와 정상 설정의 검사 통과 |
| 파일 부재 처리 | 기존 파일 부재 보고 이후 수정 진행 승인 | 로그·저장 경로 대조, 파일 부재와 일반 장애의 분류, API 수정과 회귀 검사 | 명시적 부재의 404 반환, 인증·소유권 경계와 기존 기록 보존 |
| 입력 본문 보존과 이용 시나리오 | AI가 제안한 본문 보존 방식 승인, 실제 이용 순서에 따른 점검 요청 | 본문 보존·후보 선택·확정·편집 이탈 경로 검사, 자동 회귀와 실기기 재시험 | 각 시나리오의 기대 동작과 확인한 실행 범위를 구분 |

이 과정에서 주도자는 작업의 목적과 진행 범위를 정했고, AI는 구체적인 분석·구현·시험을 지원했습니다. 입력 본문 보존은 AI 제안에 대한 승인으로 기록했으며, 최초 기술 제안의 주체를 바꾸어 설명하지 않았습니다.

## 근거의 범위

이 요약은 요구사항에서 분석·수정·검증까지 이어진 협업 과정을 설명합니다. 특정 코드의 직접 작성이나 결함의 최초 발견을 주도자에게 귀속하는 증거는 아닙니다. 코드 전체의 작성자를 절대적으로 증명하지 않으며, 과거 Git 공동작성 표시는 보조 근거로 취급합니다.

현재 독립 예제와 CI는 현재 예제의 동작을 검증합니다. 과거 서비스 개발 작업을 다시 실행한 기록은 아닙니다. AI 활용에 따른 생산성 향상률이나 코드 생성 비율은 측정하지 않았습니다.
